# 泳池水质人格 · 你家池子是什么性格？

一个面向泳池场馆运营者的趣味科普测评。用 5 个真实的水质管理维度、30 道情景题，
测出你的泳池是 7 种人格中的哪一种。

## 7 种结果类型

水界卷王 · 补药狂魔 · 老干部池 · 仪式感管家 · 打不死的水 · 浑水摸鱼 · 绿水侠（隐藏款）

## 5 个水质维度

| 维度 | 覆盖的失效链路 |
|---|---|
| 余氯自律度 | 消毒剂投加不规律 |
| 循环持久力 | 水力停留时间不足 |
| 清澈感知力 | 问题发现得太晚 |
| 负荷承载力 | 有机污染超出处理能力 |
| 突发应变力 | 出事后救不回来 |
